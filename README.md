# War card game

Play war card game (also known as battle) with 2 or more players.

### Dependencies

<!-- TODO: add link and version -->
* Java
* Maven

### How to play

1. clone this repo
2. in a terminal go to the cloned repo `` cd ~/<download folder>/war ``  
3. compile with maven `` mvn clean package ``
4. run with maven `` mvn exec:java -Dexec.mainClass="org.ausderau.Main" ``
